MON CARNET DE BUDGET - application synchronisee

1) Cree un projet gratuit sur supabase.com, puis colle supabase-setup.sql dans SQL Editor > Run.
2) Authentication > Sign In / Providers > Email : desactive "Confirm email".
3) Project Settings > API Keys : copie l'URL du projet et la cle PUBLIQUE (anon / publishable).
4) Ouvre config.js, colle les deux valeurs entre les guillemets, enregistre.
5) Mets tous les fichiers de ce dossier sur GitHub Pages (Add file > Upload files).
6) Dans l'app : Profil > Creer un compte (1er appareil), puis Se connecter sur les autres.
Ne mets JAMAIS la cle secrete / service_role dans config.js.
